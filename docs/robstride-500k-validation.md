# RS-06 500 kbps 변경 및 실기 재검증

2026-11-12 23:51 KST에 검증을 마쳤다. 결과: **통과**.

1 Mbps에서 ID 127 모터에 Type 23 프레임 `1700FD7F#0102030405060200`을
보냈고 기존 MCU 고유 ID의 응답을 받았다. 사용자가 모터 전원을 다시 켜고
can0를 500 kbps로 설정한 뒤 같은 모터가 500 kbps에서 응답하는 것을 확인했다.
모터 ID는 변경하지 않았다.

전원 재인가 전에는 모터 응답이 없어 오류 상태가 발생했다. 재인가 후 정상
응답을 확인했고, 모션 전에 읽기 전용 조회를 반복해 오류 카운터가 0으로
복구된 것을 확인했다. 그때까지의 누적 bus-off 카운터는 2이며, 이를 최종
시험 전 기준값과 비교했다. 최종 시험 중 새 오류는 없었다.

첫 500 kbps 모션 시험은 정·역회전과 비활성화는 확인했지만 zero 명령 후
0.6초 구간의 평균 속도가 −0.0641 rad/s여서 기존 ±0.05 기준을 넘었다.
같은 구간의 위치 변화 기준 속도는 −0.0246 rad/s였고, 종료 후 읽기 속도와
전류는 모두 0이었다. 시험 도구의 zero 구간을 1초로 늘리고 허용 기준은
유지해 다시 실행했다. 최종 zero 구간 평균은 −0.01051 rad/s로 통과했다.
모터 플러그인과 속도 제어 게인은 변경하지 않았다.

모터는 정지·비활성화했으며 can0는 500 kbps, rover 프로파일은 flat을
유지했다. 모터에서 읽힌 제한값은 1 A, acc_rad=0.5, canTimeout=4000이다.
시험 기록과 이전 실패 기록은
[`validation/robstride-500k-2026-11-12`](validation/robstride-500k-2026-11-12)에 보관했다.

이번 결과는 단일 모터의 저속 구동과 정지를 검증한다. 4륜 통합 주행,
장착 방향, 부하 성능, 의도적인 통신 차단 시험은 포함하지 않는다.
