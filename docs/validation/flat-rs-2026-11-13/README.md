# 철회된 단일 모터 ROS 호스트 시험 기록

이 폴더의 결과는 `robstride_flat_motor`라는 별도 ROS 노드가
`RobstrideDevice` 플러그인을 직접 호스팅한 실험이다. ros2_control,
CanHW, 기존 주행 컨트롤러를 거치지 않았으므로 정상 rover SW 구성의
검증 결과로 사용할 수 없다.

사용자가 flat rover의 목적을 정상 rover SW 구성 검증이라고 명확히 한 뒤,
이 우회 노드·선택 옵션·관련 코드와 설치 실행 파일은 철회했다.
여기에는 실험의 한계와 경위를 보존하기 위해 당시 결과만 남겼다.
